# Deleted Message Saver (Kotlin, Android)

Сохраняет текст входящих уведомлений и показывает сообщения, которые собеседник потом удалил.

## Сборка
1. Android Studio -> Open -> папка проекта (Gradle wrapper подтянется сам).
2. Run на телефоне или эмуляторе (Android 8.0+).
3. В приложении нажми "Включить доступ" и разреши доступ к уведомлениям.
4. Если телефон агрессивно убивает фоновые приложения (Xiaomi, Huawei, Samsung),
   отключи для приложения оптимизацию батареи.

## Ограничения
- Видит только то, что пришло уведомлением на ЭТОТ телефон после включения доступа.
- Не сработает, если чат был открыт или замьючен, или уведомления отключены.
- Telegram при удалении просто убирает уведомление, поэтому надёжно определить удаление нельзя.
- Помечается последнее сообщение контакта: при нескольких быстрых сообщениях возможна неточность.
- Тексты "сообщение удалено" в DELETED_MARKERS (MessageListener.kt) можно дополнить под свой язык.
- Данные хранятся только локально в SQLite на телефоне.
